# VEYLO — PROJECT BLUEPRINT

Project: Veylo (working brand name)
Type: Global Digital Discovery & Technology Platform
Audience: Worldwide
Design: Modern tech-inspired UI
Theme: Light
Stack: Next.js, TypeScript, Tailwind CSS, Supabase and Vercel.

## 1. Project Vision

Veylo is a global digital discovery platform that helps people discover useful online opportunities, freebies, rewards, technology, digital tools, tutorials and reviews.

The goal is to build more than a traditional blog: a modern, searchable destination for discovering valuable digital resources.

Motto: Discover what's worth knowing.

## 2. Main Categories

1. Freebies: Free software, resources, trials and giveaways.
2. Rewards: Cashback, referral programmes and earning platforms.
3. Technology: Apps, AI tools, software and digital services.
4. Tutorials: Step-by-step guides and technology explanations.
5. Opportunities: Remote opportunities, campaigns and online programmes.
6. Reviews: Honest platform reviews and comparisons.

## 4. Core Features

### Public website

- Modern responsive homepage.
- Search and category navigation.
- Featured and trending content.
- Article pages and related articles.
- Tags, filters and pagination.
- Newsletter subscription.

### Opportunity directory

- Search and filter opportunities.
- Country-specific eligibility.
- Active, upcoming, expired and paused statuses.
- Requirements and reward information.
- Expiration and verification dates.
- Official application links.
- Report expired or broken opportunities.

### Admin dashboard

- Create, edit and delete articles.
- Rich-text editor and image uploads.
- Drafts and scheduled publishing.
- Manage categories and tags.
- Create and update opportunities.
- Manage expiry dates and verification.
- View website analytics.

### Future features

- Visitor accounts.
- Bookmarks and saved opportunities.
- Comments and moderation.
- Community opportunity submissions.
- Affiliate tracking.

## 5. Database

Use Supabase PostgreSQL.

Initial entities:

- Users
- Posts
- Categories
- Tags
- Opportunities
- Eligibility
- Sources
- Media
- Reports
- Bookmarks
- Newsletter subscribers
- Affiliate links

Keep opportunities separate from ordinary articles while allowing them to be linked.

## 9. Development Roadmap

- Phase 1: Project setup, design system, navigation and homepage.
- Phase 2: Article pages, categories, search and content system.
- Phase 3: Opportunity directory, filters, eligibility and expiry management.
- Phase 4: Admin dashboard, authentication and publishing CMS.
- Phase 5: SEO, analytics, newsletter and performance optimisation.
- Phase 6: User accounts, bookmarks, community features and advanced monetisation.
- Phase 7: Testing, security checks and public launch.

## 10. Development Rules

- Follow the roadmap without silently skipping features.
- Maintain a checklist of completed and pending tasks.
- Test features before moving to the next phase.
- Keep code modular and maintainable.
- Use database-driven content instead of hardcoded production data.
- Never present fictional opportunities as real.
- Prioritise security, accessibility and mobile responsiveness.
- Update the project blueprint when major decisions change.
